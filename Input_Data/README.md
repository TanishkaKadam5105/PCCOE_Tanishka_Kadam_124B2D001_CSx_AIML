Input Data — AutoDoc AI

Dataset Description
This folder contains the synthetic automotive High-Level Design (HLD) PDF used to test the AutoDoc AI application.

 Input File
- Filename: Sample_Automotive_HLD_AutoDoc_AI.pdf
- Format: PDF
- Pages:3
- Data type: Text-based synthetic technical document

Document Content
The sample describes an obstacle detection and automatic braking support system. It includes component responsibilities, message relationships, system warnings, and example questions with expected answers.

Purpose
The document is used to test PDF text extraction, semantic search, retrieval of relevant passages, AI-generated answers, and source-page references.

Data Source and Limitations
The document is synthetic and intended for educational testing. It is not an official AUTOSAR specification, an OEM document, or a validated automotive safety design. Results obtained using this sample do not establish performance on real-world technical documents.
